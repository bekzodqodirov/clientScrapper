## 2. First-touch rules

### 2.1 Channel order (per lead, in this order; skip a channel only if contact is absent)

1. **Telegram DM from the manager's own account** (GramJS-connected, so the chat lands in the CRM). Default for A, B, E, F.
2. **Phone call** 10:00–17:00 Tashkent time, only if a *business* phone is public (directory, OLX business card, website) — default first touch for C and D (procurement staff answer phones, not Telegram).
3. **Instagram DM** only for B/E shops with no Telegram; ask to move to Telegram in the first reply.
4. **Visit** only after a reply, or for A when the lead is a stall/warehouse in a Tashkent bazaar and the manager already has a route there (`[OWNER TO CONFIRM policy]`).
5. **Never**: SMS blasts, bot accounts, bulk senders, auto-DM scripts, group-chat spam, adding to groups/channels, calls outside 09:00–18:00 (statutory window for mobile advertising from 1 Nov 2026 — apply it to Telegram too).

### 2.2 Timing

- Telegram DMs: Mon–Sat 10:00–17:00; avoid Friday 12:00–14:00; never Sunday, never after 18:00 or before 09:00.
- Calls: Mon–Fri 10:00–12:00 and 14:30–17:00.
- Seasonal: Aug–Oct = "book your pre-CNY truck" message; Jan = "CNY closures (Irkeshtam/Khorgos) — plan now"; Oct–Dec = Gisht-Kuprik reopening update.
- Batch size: clientScrapper pushes ≤ N leads/day/manager (`per-source daily cap` in ERP); recommended N = 15 so that each one gets a hand-written message.

### 2.3 Who writes

- A named human manager from their own account; the first line carries their real name. No bot, no shared "GSR Sales" account, no Telethon/MIYA auto-send for first touch.
- MIYA's gated sender may be used only for **approved follow-ups** (owner/manager approves the outbox row; daily cap, min gap, quiet hours, kill switch already exist). Set MIYA caps for this use: ≤20 new-contact messages/account/day, ≥3 min gap, quiet hours 18:00–10:00, hard stop for the account if any PEER_FLOOD or a `@SpamBot` restriction appears.
- Account hygiene: aged accounts (>6 months), real photo, name + "GSR Logistics" in bio, phone number visible to contacts, Telegram Premium (vendor sources say it raises tolerance; unverified but cheap). New accounts warm up 4 weeks with ≤5 cold DMs/day.

### 2.4 What the first message MAY contain

- Greeting with name; who you are (name, GSR Logistics, Tashkent, since 2018).
- One **public** observable reason for writing (their OLX wholesale listing, Uzum store, exhibitor list, directory card, Telegram channel post). Public source only.
- One or two concrete facts: own receiving points Yiwu/Guangzhou/Kashgar; measurement + photo report; per-m³ by density; 15–25 days; containers 20–35 days.
- Exactly one question (volume / next shipment).
- The opt-out line.
- Length 50–90 words, plain text.

### 2.5 What it MUST NOT contain

- Any price figure before goods + density + origin city are known (quote only the *range* 110–320 $/m³ and only if asked).
- "Bojsiz/без пошлин", "eng tez/самая быстрая", "100% kafolat/гарантия", "muammosiz/без проблем".
- References to their customs declarations, import volumes, STIR, tax status, or anything from non-public datasets ("we see you imported 40 t last quarter" is forbidden — it signals surveillance and risks personal-data complaints).
- Links, images, price lists, PDFs, voice notes, forwarded posts (spam signals; also Telegram flags link-heavy first messages).
- Competitor names, discounts, urgency ("faqat bugun"), multiple messages in a row, emojis beyond one.
- A request for documents, payment, or STIR.

### 2.6 Opt-out line (mandatory, last sentence)

- UZ Latin: `Agar qiziq bo'lmasa, "yo'q" deb yozing — boshqa yozmayman.`
- UZ Cyrillic: `Агар қизиқ бўлмаса, «йўқ» деб ёзинг — бошқа ёзмайман.`
- RU: `Если неактуально — напишите «нет», больше не побеспокою.`

Any "yo'q / нет / не надо / stop" → `do_not_contact = true` the same day, acknowledged with one line ("Tushunarli, rahmat." / "Понял, спасибо.") and no further contact.

### 2.7 Follow-up cadence (max 4 touches, 14 days)

| Day | Touch | Content |
|---|---|---|
| 0 | DM / call | First message (scripts §3) |
| 3 | DM bump (only if no reply) | One sentence: "Ko'rgan bo'lsangiz kerak — qisqa javob yetarli: oyiga necha kub?" |
| 7 | Value message | One factual, dated item relevant to their segment (e.g., Gisht-Kuprik reopening schedule; customs-fee −30% from 1 Oct 2026; CNY closure calendar; PKM-352 list check offer for factories). No ask except "foydali bo'lsa, yozing". |
| 14 | Close | "Hozircha dolzarb emas shekilli. Keyingi chorakda bir yozsam maylimi? Yo'q desangiz, yopaman." |
| 15+ | Stop | Mark `no_response`; cooling 6 months; one re-touch allowed then, only with a new public signal. |

If a call is the primary channel: Day 0 call → if no answer, 1 Telegram DM same day ("Qo'ng'iroq qildim — qulay vaqt ayting") → Day 3 call → Day 7 DM value → Day 14 close.

### 2.8 Stop immediately when

Explicit no; DNC flag; reported/blocked; wrong person or B2C; company closed; they are a forwarder/competitor; <3 m³ with no growth; 4 touches without reply; phone belongs to a private individual not tied to the business; any sign of a government body or a sanctioned/unreliable-supplier-list entity (`xarid.uzex.uz` unreliable list) — route to owner.

### 3.3 Objection handling (top 8)

Format: what it usually means → how to answer (rule) → UZ Latin line → RU line.

**1. "Already have a forwarder" / "Kargo bor" / "Уже есть карго"**
Meaning: fine, or locked by habit; sometimes a relative. Rule: don't attack; ask for the one thing they'd change; offer a parallel 3 m³ test on one truck. Never badmouth.
- UZ: `Yaxshi, demak jarayon tanish. Bitta savol: o'tgan 3 ta yukda narx, muddat yoki o'lchovda ajablangan joyingiz bo'ldimi? Bo'lmasa — zo'r. Bo'lsa, keyingi partiyadan 3 kubini biz bilan sinab ko'ring, qolganini o'zgartirmaysiz.`
- RU: `Хорошо, значит процесс вам знаком. Один вопрос: за последние три груза было что-то, что удивило — по цене, сроку или замеру? Если нет — отлично. Если да, попробуйте с нами 3 куба из следующей партии, остальное не трогайте.`

**2. "Price" / "Qimmat" / "Дорого" (or "others quote X $/m³")**
Meaning: comparing headline per-m³ without density, intake fees, Tashkent delivery, customs. Rule: never match blind; ask for their last invoice line items; quote only after goods + density + city; show the formula.
- UZ: `Narxni zichliksiz solishtirib bo'lmaydi: bizda 110 dan 320 $/kub gacha, zichlik va tovarga qarab. Oxirgi hisob-fakturangizni yuboring — o'sha tovar uchun bizning yakuniy, Toshkentgacha hamma narsa kirgan raqamni yozma beraman. Keyin solishtirasiz.`
- RU: `Без плотности цены не сравниваются: у нас от 110 до 320 $/м³ в зависимости от плотности и товара. Пришлите последний счёт — дам письменно итоговую цифру по этому же товару до Ташкента со всеми составляющими. Тогда сравним честно.`

**3. "Trust" / "Sizni tanimayman" / "Не знаю вас" (prepayment-scam fear)**
Meaning: real, given Telegram prepayment fraud in UZ. Rule: verifiability, not promises: legal entity, STIR, office address, contract, own warehouses, 400+ clients, offer to visit office/warehouse in Tashkent, reference client in the same bazaar/segment (with that client's consent). Payment structure `[OWNER TO CONFIRM]` — never invent "pay after delivery".
- UZ: `To'g'ri qilasiz. Biz Imex Services MChJ, 2018-yildan, STIR va ofis manzilini yuboraman, shartnoma tuzamiz, Toshkentdagi omboringizga kelib ko'rishingiz mumkin. Istasangiz, [bozor/soha]dan bizning mijoz bilan bog'lab qo'yaman. Birinchi yukni kichik qiling — 3 kub.`
- RU: `Правильно делаете. Мы ООО Imex Services, с 2018 года, пришлю СТИР и адрес офиса, работаем по договору, склад в Ташкенте можно посмотреть лично. Если хотите, свяжу с нашим клиентом из вашей сферы. Первый груз сделайте маленьким — 3 куба.`

**4. "Customs problems" / "Bojxona bilan muammo bo'ladi" / "С таможней будут проблемы"**
Meaning: fear of valuation adjustments, TN VED disputes, fines for grey schemes. Rule: GSR does GTD, TN VED classification, duty + VAT 12% calculation in advance; mention the Oct 2026 fee reduction and (for factories) the PKM-352 check; never say "no problems" or "duty-free"; say customs decides, GSR prepares.
- UZ: `Bojxonani biz o'zimiz rasmiylashtiramiz: TN VED kodi, boj va 12% QQS oldindan hisoblab beriladi, GTD bizning nomimizdan. Qaror bojxonaniki, lekin hujjat to'g'ri bo'lsa, tortishuv kam bo'ladi. Uskuna bo'lsa, PKM-352 ro'yxatini ham tekshiramiz.`
- RU: `Таможню оформляем сами: код ТН ВЭД, пошлина и НДС 12% считаются заранее, ГТД на нас. Решение принимает таможня, но при правильных документах споров меньше. Если это оборудование — проверим перечень ПКМ-352.`

**5. "Payment terms" / "To'lov qanday?" / "Какие условия оплаты?"**
Meaning: cash-flow; wants deferral or pay-on-arrival. Rule: state GSR's actual terms only (`[OWNER TO CONFIRM: prepayment %, payment on arrival in Tashkent, bank/cash/UZS/USD, invoices for legal entities]`); never promise deferral; offer split by milestone if that is GSR policy.
- UZ: `To'lov shartlari: [OWNER TO CONFIRM]. Yuridik shaxslarga hisob-faktura va shartnoma bo'yicha. Birinchi yukda kichik hajm bilan shartlarni o'zingiz ko'rasiz.`
- RU: `Условия оплаты: [OWNER TO CONFIRM]. Для юрлиц — по договору и счёту. На первом небольшом грузе условия увидите сами.`

**6. "Kashgar vs Yiwu route" / "Kashg'ar orqali arzonroq/tezroq-ku" / "Через Кашгар быстрее"**
Meaning: valley clients know the Irkeshtam corridor. Rule: GSR has both; choose by origin of goods and destination; Kashgar suits valley-bound cargo sourced in western China or trucked to Kashgar; Irkeshtam has periodic closures (CNY, ad-hoc); Yiwu/Guangzhou suit east-China sourcing; give both written.
- UZ: `Ikkalasi ham bizda bor. Tovar Yiwu/Guangzhouda bo'lsa, Kashg'argacha o'zi 4–5 ming km — ko'pincha Xorgos orqali to'g'ri keladi. Yuk vodiyga va Kashg'arga yaqin joydan bo'lsa, Kashg'ar punktimiz qulay, faqat Irkeshtam Yangi yil va boshqa kunlarda yopiladi. Ikkala hisobni yonma-yon beraman, tanlaysiz.`
- RU: `У нас есть оба маршрута. Если товар в Иу/Гуанчжоу, до Кашгара его ещё везти 4–5 тыс. км — обычно выгоднее через Хоргос. Если груз в долину и поставщик ближе к Кашгару, удобен наш пункт в Кашгаре, но Иркештам периодически закрывают (китайский Новый год и не только). Дам оба расчёта рядом — выберете.`

**7. "Insurance" / "Yuk yo'qolsa kim to'laydi?" / "А если груз потеряется?"**
Meaning: past loss or damage. Rule: explain intake count + photo report as proof of what entered; carrier liability is limited by weight under conventions; offer insurance at GSR's rate (`[OWNER TO CONFIRM %; market 0.5–3% of invoice value]`), name the insurer, what is covered, how a claim is filed; never "100% compensation".
- UZ: `Avval oldini olamiz: qabulda joylar sanaladi, foto bilan yoziladi. Istasangiz sug'urta rasmiylashtiramiz — [OWNER TO CONFIRM %] tovar qiymatidan, qoplash shartlari yozma. "100% kafolat" demayman, chunki buni hech kim halol va'da qila olmaydi — hujjat va sug'urta bilan ishlaymiz.`
- RU: `Сначала профилактика: на приёмке пересчитываем места и фиксируем фото. По желанию оформляем страховку — [OWNER TO CONFIRM %] от стоимости товара, условия выплаты письменно. «100% гарантию» не обещаю — её честно никто дать не может, работаем документами и страховкой.`

**8. "Timing" / "15–25 kun ko'p" / "Долго" (or "now is a bad time")**
Meaning: either need speed or deferring the decision. Rule: for speed → air 9–12 $/kg or rail/container timeline, plus seasonal honesty (Khorgos queues Sep–Nov and pre-CNY; Gisht-Kuprik closed, reopening Q4 2026); for deferral → fix a date and leave.
- UZ: `Shoshilinch bo'lsa — avia 9–12 $/kg, 1 haftadan kam. Fura 15–25 kun real raqam, "eng tez" deb aldamayman: sentabr–noyabr va Yangi yil oldi Xorgosda navbat bo'ladi, shuning uchun oldindan joy olamiz. Hozir vaqti emas desangiz — qachon yozay, [sana]mi?`
- RU: `Если срочно — авиа 9–12 $/кг, меньше недели. Фура 15–25 дней — реальная цифра, «самую быструю» не обещаю: в сентябре–ноябре и перед китайским Новым годом на Хоргосе очереди, поэтому бронируем заранее. Если сейчас не время — когда написать, [дата]?`

## 5. Metrics and weekly review ritual

### 5.1 Funnel metrics (per week, per manager, per source, per segment)

| Metric | Definition | Initial target (hypothesis; recalibrate after 4 weeks) |
|---|---|---|
| Pushed | leads accepted by ERP (not dropped/joined) | capacity-bound: ≤15/manager/day |
| Accepted in SLA | "Bog'landim" pressed within 1 working day | ≥90% |
| First touch sent | message/call logged within 1 working day | ≥90% |
| Reply rate | any human reply within 14 days / first touches | ≥8% Telegram DM (benchmarks 3–8% email; personalised DM should beat it) |
| Positive reply | interested or qualified / replies | ≥40% |
| Qualified rate | ≥3 m³ or FTL/container confirmed / pushed | ≥10% |
| Quote sent | written calculation sent / qualified | ≥80% within 2 working days |
| Won first shipment | first paid shipment / quotes | ≥20% within 45 days |
| Repeat | 2nd shipment within 90 days / won | ≥50% |
| Time-to-first-shipment | median days push → first shipment | ≤45 |
| Revenue per 100 leads | m³ × tariff from won leads / 100 pushed | tracked, no target yet |

### 5.2 Hygiene and risk metrics (gate the whole program)

| Metric | Threshold → action |
|---|---|
| Wrong-contact rate (wrong_contact + not_b2b) / pushed | >15% for a source → source weight halved; >30% → source paused |
| DNC rate (asked) / first touches | >5% per manager → review that manager's messages; >5% per segment → rewrite script |
| Reports/blocks (manager blocked by lead, `@SpamBot` restriction, PEER_FLOOD) | any restriction → that account stops cold DMs 7 days; 2 in a month → owner review |
| Messages outside 10:00–17:00 | >0 → warning; repeated → remove account from outbound |
| Leads with blank fill-back fields >2 days | >10% → supervisor escalation |
| Duplicate pushes (ERP "joined" / existing client attach) | >10% → scraper dedupe bug |
| Cost per qualified lead (scraper API/LLM spend ÷ qualified) | tracked vs MIYA/Claude cost caps |

### 5.3 Weekly review ritual — Monday 10:00, 45 minutes, in Uzbek

Participants: owner (chair), sales supervisor, each outbound manager, the person running clientScrapper. Inputs auto-generated Sunday night from ERP (funnel by manager/source/segment, hygiene table, list of all `replied_not_interested` with reasons, all DNC with reasons, top 5 won and top 5 lost with notes).

Agenda:
1. (5 min) Hygiene table first — any threshold breached? Decide pauses before anything else.
2. (10 min) Funnel by source and segment — which sources produce qualified leads, which produce wrong contacts; set next week's source weights and per-source caps in clientScrapper.
3. (10 min) Message review — read 3 best-replied and 3 worst first messages verbatim; keep one script variant per segment as "champion", one "challenger" for the week (A/B by manager, same segment, same days).
4. (10 min) Objections heard this week — count by the 8 categories; update §3.3 lines; capture any new forbidden-wording slip.
5. (5 min) Pipeline — every `qualified` and `quote_sent` lead older than 7 days gets a next step and date.
6. (5 min) Decisions logged: source weights, caps, script champion/challenger, DNC additions synced to scraper, any manager account rotation.

Outputs written back the same day: scraper config (source weights, caps, segment thresholds), ERP routing rules (m³ ranges, keywords), updated script file, and a one-screen summary posted to the sales Telegram group.

Monthly add-on (first Monday): recalibrate scoring with the month's outcome labels; review legal posture (consent/DNC log completeness, no SMS, calls only in window, personal-data DB registration status per CabMin 71/2020 — owner's legal list) and check whether the customs Excel carries importer names (open question) before any customs-derived targeting is used in messaging.
